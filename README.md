# Lifejourney

一个使用 Vue 3、Pinia、Hono REST API 和内存存储实现的最小可用微博示例。

## 功能

- 发布最多 280 字的动态
- 查看已发布动态
- 使用 Pinia 管理状态
- 使用 Hono REST API 保存数据
- 使用后端内存存储保存当前服务进程内的数据
- 可清空动态

## 使用

安装依赖：

```bash
npm install
```

启动开发服务器：

```bash
npm run dev:api
npm run dev
```

运行测试：

```bash
npm test
```

构建：

```bash
npm run build
```
